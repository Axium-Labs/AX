# Web Research

When web research is needed:

1. Choose a retrieval method from the tools currently available, according to
   the evidence needed. Search is optional; a known primary source can be read directly.
2. When search is useful, formulate distinct queries covering the relevant aspects.
   Batch independent queries when the selected tool supports it.
3. Use titles, links and snippets first when they provide enough evidence.
4. Retrieve page bodies only when deeper evidence is needed.
5. Batch independent page retrievals when supported, and request only enough
   results or pages to answer the question reliably.
6. Prefer primary, official, and authoritative sources.
7. Avoid repeating equivalent searches.
8. Stop searching once enough evidence is available to answer accurately.
