# Web Research

When web research is needed:

1. Generate 1-3 distinct search queries covering different aspects of the request.
2. Submit all queries in one web search call.
3. Use structured search results and snippets first.
4. Do not fetch pages when snippets already provide sufficient evidence.
5. If deeper evidence is needed, fetch all necessary URLs in one batch.
6. Prefer primary, official, and authoritative sources.
7. Avoid repeating equivalent searches.
8. Stop searching once enough evidence is available to answer accurately.
