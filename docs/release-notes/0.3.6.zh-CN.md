# AX 0.3.6

[English](0.3.6.md) | **简体中文**

- 网页搜索路由至配置的 Bocha、Brave 和 SearxNG 提供商，DuckDuckGo 作为最终回退。新增延迟追踪、有界对冲、熔断器、提供商超时及规范化 URL 去重；网页抓取行为不变。
- 澄清工具指引：搜索失败展示提供商诊断，不自动通过 shell/Python 绕过网页搜索。用户明确指定的替代方式仍可在现有权限内使用。
- 新增原生 Anthropic、Gemini、Vertex、Bedrock、Radius 适配器，以及 Azure Responses 和 Cloudflare Gateway/Workers AI 配置。共用运行时和目录分发，跨轮次保留签名推理元数据。
- 更正支持／认证标签，明确报告缺失的提供商配置。

验证：工作区 586 项测试通过，3 项忽略；开发期间完成 cargo fmt 和 clippy。Windows x64 Release 构建通过；发布时未额外运行测试。

尚未使用真实凭据验证账户级访问及付费推理。Anthropic/Radius 浏览器 OAuth、Google external-account 联合 ADC 和 GitHub Copilot 仍不可用。Vertex 支持 Google publisher 模型；Bedrock 支持 ConverseStream 模型。
