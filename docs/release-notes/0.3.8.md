# AX 0.3.8

- Run SSH project tasks with the local AX runtime and its configured SSH tool;
  remote hosts do not need a separate AX installation.
- Remove the fixed SSH-host concurrency cap so a session can target multiple
  configured hosts.
- Preserve provider-supported reasoning-effort values through model metadata
  and CLI selection instead of mapping them to a fixed set of labels.
- Extend the existing optional distributed collaboration and workspace flow.

Validation during development: workspace Rust tests, formatting and clippy,
CLI release build, and SSH/local-runtime regressions passed. No additional
release-time test suite was run.
