# AX 0.3.2

[English](0.3.2.md) | **简体中文**

- CLI、TUI 和 ACP/Crew 提示适配器共用 LocalChildHost 创建、项目作用域及控制器／子代理执行预算。
- 保留单一 Agent Loop；显式子任务队列通过现有子执行器自动顺序消费运行任务。
- 编号／项目符号要求仍是普通提示内容；真正任务必须在数据发现之后由模型显式调用 task_queue start 创建。
- 接受完整任务输入字符串和结构化 title/input 任务；隔离子代理接收完整输入，控制器进度也保留该输入。
- 任务分发前允许同 Goal 重新规划，并归档错误的旧队列。持久化分发标记以保护中断工作，兼容旧字符串检查点。
- 新增使用真实 LocalChildHost 的前端回归测试：ACP 三个顺序子任务、首子任务失败后续接、读取数据后动态创建 23 个任务，以及基准说明式列表。

验证：工作区测试、Clippy 和格式检查；Windows x64 Release 构建及 SHA256 验证的发布资产。
