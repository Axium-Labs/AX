# AX 0.3.3

[English](0.3.3.md) | **简体中文**

- 完整 Evolution Experience 仅保存在追加式 `experiences.jsonl` 中；生命周期和调度控制保存在带版本的 `ledger.json` 中。
- 通过持久化字节游标和有界批次消费 Experience，支持 ID 去重及重启安全的旧格式迁移。
- 保留现有 Skill 生命周期、动作、Memory 作用域及 `SKILL.md` 行为。

验证：`cargo test --workspace`（518 项通过，3 项忽略）；`cargo clippy --workspace --all-targets`（通过，保留已有 CLI／工具警告）；`cargo check --workspace`（通过）。Windows x64 Release 构建：通过；`ax.exe --version` 输出 `ax 0.3.3`。
