# AX 0.2.5

[English](0.2.5.md) | **简体中文**

工具策略现在会在同一模型响应中批量发起已知相互独立的搜索和读取，优先精确搜索后读取有界上下文，并采用按行定位的原子多块补丁。失败恢复先进行本地诊断和最小检查，再做完整验证。

工具结果保留无损原始输出，同时向模型投影有界摘要和诊断信息。路径缺失及补丁冲突会附带恢复上下文。现有权限、DAG 执行、Session/MCP 职责保持不变。

`benchmark/` runner 固定使用三个经用户批准的本地 SWE-bench dev 任务、GPT-6 Luna 和低推理强度，在隔离快照中运行，以官方验收测试评分。附带结果记录了编码开始前发生的网关 403 失败，不构成有效性能对比。

此快照同时保留工作区中的能力导入和技能进化变更。
