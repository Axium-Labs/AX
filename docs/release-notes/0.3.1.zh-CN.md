# AX 0.3.1

[English](0.3.1.md) | **简体中文**

- 修复空目录、无匹配搜索和非致命工具失败后，长任务无法继续执行的死锁。
- 允许任何观测之后重试、重新规划或开始新步骤；进度和恢复指引改为建议。
- 恢复期间仍可使用 shell/MCP 及读取、搜索、列表诊断，保留权限、沙盒、依赖和资源约束。
- 从旧恢复检查点还原最初声明的作用域，并记录失败工具调用及资源元数据。
- 失败任务可直接结束，无需强制恢复，使独立子任务能够继续。
- 新增观测、诊断、重试、任务续接、检查点兼容以及权限／作用域执行的回归覆盖。

验证：`cargo test --workspace -- --test-threads=1`（421 项通过，1 项平台特定测试忽略）；`cargo clippy --workspace --all-targets`；`cargo fmt --all -- --check`。
