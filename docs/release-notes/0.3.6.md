# AX 0.3.6

- Route web searches through configured Bocha, Brave and SearxNG providers, with DuckDuckGo as the final fallback. Add latency tracking, bounded hedging, circuit breakers, provider timeouts and canonical URL deduplication; preserve web fetch behavior.
- Clarify tool guidance: search failures surface provider diagnostics instead of automatically bypassing web search through shell/Python. Explicit user alternatives remain available within existing permissions.
- Add native Anthropic, Gemini, Vertex, Bedrock and Radius adapters, Azure Responses and Cloudflare Gateway/Workers AI configuration. Share runtime and catalog dispatch; preserve signed reasoning metadata across turns.
- Correct support/authentication labels and report missing provider configuration explicitly.

Validation: 586 workspace tests passed, 3 ignored; cargo fmt and clippy completed during development. Windows x64 release build passed. No additional release-time tests.

Account-level access and paid inference were not tested with live credentials. Anthropic/Radius browser OAuth, Google external-account federation ADC and GitHub Copilot remain unavailable. Vertex supports Google publisher models; Bedrock supports ConverseStream models.
