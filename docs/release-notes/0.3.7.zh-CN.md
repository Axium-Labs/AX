# AX 0.3.7

[English](0.3.7.md) | **简体中文**

- 新增可主动启用的 `ax crew worker worker.json`，在隔离的每次尝试工作区中，通过现有 ACP 运行时执行分布式分配。
- 新增 `collaboration` 工具，支持能力发现、异步委派、结果／错误／Observation 读取、Artifact 交换和 Workflow State 检查点。
- 支持每个 Host 多个 AX 实例及每个 AX 并发执行，各实例有独立本地模型、能力、记忆／配置和权限。
- 使用 AXCrew 所有权／incarnation／generation 租约、稳定子请求 ID 和显式检查点恢复持久工作；无需常驻 Coordinator Agent，也无需 AX 之间直接高频通信。
- 保留现有 Crew 设备桥接，仅当旧 cwd 解析为已注册本地项目根目录时接受它。普通 AX 启动及核心 Agent Loop/Subagent/Task/Session/Memory 行为不变。

开发期间验证：工作区 Rust 测试、fmt 和 clippy 通过；clippy 保留已有无关警告。真实三 AX 进程协作及旧 Crew 控制进程测试通过。Windows x64 Release 构建通过；发布时未额外运行测试。

分布式进程场景在一台 Windows 计算机上使用逻辑 Host、假模型，并显式关闭沙盒。尚未验证物理多 Host 网络、TLS 或 GPU 隔离。执行语义为至少一次；资源只是调度预留。分布式控制面需要 AXCrew 0.3.3。参见[配置与限制](../distributed-collaboration.zh-CN.md)。
