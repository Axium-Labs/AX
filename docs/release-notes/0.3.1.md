# AX 0.3.1

- Fix long-task liveness deadlocks after empty catalogs, no-match searches and nonfatal tool failures.
- Allow any observation to precede retry, replan or a new step; make progress/recovery guidance advisory.
- Keep shell/MCP and read/search/list diagnostics available during recovery, with permission, sandbox, dependency and resource constraints retained.
- Restore original declared scopes from legacy recovery checkpoints and record failed tool call/resource metadata.
- Allow failed tasks to finish without forced recovery so independent subtasks can continue.
- Add regression coverage for observations, diagnostics, retries, task continuation, checkpoint compatibility and permission/scope enforcement.

Validation: `cargo test --workspace -- --test-threads=1` (421 passed, 1 platform-specific test ignored); `cargo clippy --workspace --all-targets`; `cargo fmt --all -- --check`.
