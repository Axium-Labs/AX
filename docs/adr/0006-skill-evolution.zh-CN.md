# 0006. 在运行时内核之外进行技能进化

[English](0006-skill-evolution.md) | **简体中文**

状态：已接受

<a id="context"></a>
## 背景

长期使用 AX 会积累重复流程和纠正，但学习不能使每个请求多一次分析调用，也不能授权代理改写自身内核。标准 Skill 和作用域 Memory 已提供适当的行为／持久化接点。

<a id="decision"></a>
## 决策

CLI 观察已有运行时事件，将有界 Experience 交给进程内工作线程。按会话边界或累积批次分析，持久化冷却期和超时。复用内置 skill-creator 指令及现有包创建／验证。生命周期与归属元数据保存在私有账本，与标准 SKILL.md 分离。只有未修改、归属项目且 `source=evolved` 的包可自动变更。试用／活跃包在内置和用户来源之后参与普通发现；候选和归档不参与路由。综合证据与效用决定学习和退役，优先合并／压缩，再创建。

<a id="consequences"></a>
## 影响

核心循环、工具实现和权限策略保持独立且不变。普通请求仅进行有界事件收集及入队，不调用进化模型。保留本地原始学习历史。初期学习仅限项目作用域，依赖模型，对突然退出和队列过载采用尽力处理。标准导出尚不携带私有进化账本。手动编辑会使包退出自动变更管理。
