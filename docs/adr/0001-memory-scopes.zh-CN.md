# 0001. 具有可移植项目标识的作用域记忆

[English](0001-memory-scopes.md) | **简体中文**

状态：已接受

<a id="context"></a>
## 背景

AX 需要持久记忆，既能区分适用于某次对话、某个项目或所有场景的事实，又能让项目作用域数据归属于*项目*，而非文件系统绝对路径，从而使项目移动、重命名或在其他位置检出后仍保留记忆。

旧记录归属于项目绝对路径，移动／重命名后失效，共享自定义数据库时归属也不明确。以句子哈希派生事实键，难以可靠更新自然语言陈述。

<a id="decision"></a>
## 决策

- 事实分为三个作用域：**Global**（AX 主目录）、**Project**（可移植 UUID）和 **Session**（单个会话 ID）。
- 项目归属采用首次使用时创建、保存在 `.ax/project.json` 中的 UUID，独立于 `--data-dir` 和工作区路径。
- 同键优先级为 Session → Project → Global。
- 写入事实必须附当前用户请求的逐字摘录作为来源；更新和删除必须提供精确旧值，以实现乐观并发控制。
- 以路径归属的旧记录和句子哈希键以事务方式迁移；迁移标记防止已删除事实重新出现。

<a id="consequences"></a>
## 影响

- 随项目移动或复制 `.ax` 会携带项目标识；不包含 `.ax` 的新克隆会获得新标识，这是有意设计。
- 共享自定义数据库不会根据不匹配路径推断归属；其中旧的无归属项目事实需要显式迁移。
- 持久写入更安全，但需要明确用户意图；临时或含糊请求默认留在 Session 作用域。
- 检索受共享 Token 预算限制，避免记忆挤占对话，见 [memory.md](../memory.zh-CN.md)。
