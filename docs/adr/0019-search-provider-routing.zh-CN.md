# ADR 0019：搜索提供商路由

[English](0019-search-provider-routing.md) | **简体中文**

后端选择已于 2026-10-11 被 [ADR 0025](0025-native-first-hosted-search.zh-CN.md) 取代，下列引擎清单为历史记录。

日期：2026-10-04
状态：已接受

<a id="context"></a>
## 背景

BuiltinSearch 内嵌 Brave 到 DuckDuckGo 的回退，复用 fetch 激进的 2/3/8 秒传输限制，调用间丢失历史。网络或反机器人策略变化时，单一公开 HTML 引擎不可靠。

<a id="decision"></a>
## 决策

保留 SearchProvider，新增独立 Bocha、Brave、SearXNG 和 DuckDuckGo 适配器。SearchRouter 负责配置候选选择、EWMA 延迟与失败历史、临时熔断、回退及最多两请求并行的对冲。DuckDuckGo 仍是最终免密钥回退。不新增国家识别、模型请求、嵌入或主动付费提供商探测。

路由器之上查询仍并发。提供商错误或结果不足时推进候选；延迟对冲仅在需要时启动另一候选。取消和截断前，由公共规范化 URL 合并逻辑判断结果是否足够。丢弃 future 即取消全部本地工作，不保留脱离管理的请求任务。

搜索创建独立池化客户端，采用提供商专属超时，不做传输层重试，恢复由回退负责。Fetch 保持既有 HTTP 语义、限制、策略检查、错误诊断及重试。路由器惰性初始化，由同一 WebTool 的调用／克隆共享。工具元数据、错误及内置研究技能明确不鼓励通过 shell 恢复搜索。

<a id="consequences"></a>
## 影响

配置密钥／实例 URL 即可增加替代来源，无需修改 Agent Loop。路由只学习实际尝试，未尝试候选同分按配置顺序；熔断期间可持续返回错误，直到冷却结束。状态是工具内存状态，不跨进程或独立子工具共享。注入的 HTTP 客户端保留自身连接／读取限制，路由器强制总截止时间。

对冲可能产生第二家提供商费用，取消无法撤销远程工作。指引不鼓励自动绕过搜索提供商，不是全局 shell 禁令；用户明确要求替代搜索或网络诊断时，可在适用工具权限内执行。付费 API 可达性及真实延迟需要单独配置凭据；回归测试使用确定性 mock 与回环 HTTP fixture。
