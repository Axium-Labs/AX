# 0014. 建议性执行策略与工具可继续性

[English](0014-advisory-execution-policy.md) | **简体中文**

状态：已接受；修订 0009

<a id="context"></a>
## 背景

成功返回空目录时，没有正向进展就无法推进步骤；拒绝导致进入恢复，恢复又拒绝不透明 shell/MCP 工具。重试限制和观测预算可能排除所有有用的下一步。这些检查混淆了编排决策与执行安全。

<a id="decision"></a>
## 决策

保留权威 ExecutionState 历史与进度测量。调用完成后无论是否有正向进展，都从 running 转为 observed。重试、重规划、下一步及显式失败任务结果始终可选。无进展与恢复上下文只建议模型，不控制工具准入。恢复记录失败步骤、调用 ID、工具和资源，绝不收窄作用域。旧恢复快照在准入前还原最初声明的作用域。

保留权限、沙盒、显式资源作用域、冲突租约、依赖、配置预算／超时及取消约束。Resource::All 仍需独占租约，但不是禁止恢复诊断的理由。搜索回退提示只是建议，不能授权越界。失败任务无需强制恢复调用即可结束；依赖失败仍跳过依赖者，全局／致命阻塞仍停止 Goal。

<a id="consequences"></a>
## 影响

空结果／无匹配观测和非致命失败后，重试与诊断仍受相同安全策略保护，独立子任务可继续。编排可建议改变策略，不能全局锁住工具。语义成功仍不同于观测和安全授权。
