# 0012. 分层本地记忆检索

[English](0012-layered-memory-retrieval.md) | **简体中文**

状态：已接受

<a id="context"></a>
## 背景

单一加权分数混合了归属、相关性和推断重要性；检索加载所有归属记忆正文，可能用不需要的细节填满提示。AX 需要本地 SQLite、惰性加载和低延迟。

<a id="decision"></a>
## 决策

召回前过滤当前 Session/Project 及 Global 归属，保留同键作用域覆盖。最多召回 32 条词法／精确／标签／路径匹配，再以小幅使用量、置信度及类型相关时效奖励重排。作用域和来源不参与排名。以显式使用次数、置信度、来源、最后使用时间和生命周期标记替代推断重要性；用偏好、事实、决策、任务、引用和经验表达内容寿命。使用真实时间年龄，读取不使内容重新变新。

在惰性 SQLite 索引中持久化短摘要和现有 Unicode 词法特征。ContextBudget 内最多注入六条摘要，通过已有 memory 工具按键读取完整细节。不用嵌入或额外模型调用。schema 采用增量升级，保留旧 API 和序列化记录。

<a id="consequences"></a>
## 影响

归属不能抬高无关匹配排名。衰减反映内容寿命；被取代／过期内容仍可管理，但不自动召回。摘要可能不完整，模型可通过普通工具调用读取详情。旧版／导入条目首次检索时派生一次特征，此后只读索引，不加载详情正文。
