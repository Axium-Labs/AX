# 0008. 持久化轻量任务队列

[English](0008-durable-task-queue.md) | **简体中文**

状态：已接受

<a id="context"></a>
## 背景

工具轮次 DAG 隔离无法阻止执行模型在一个子任务失败后结束轮次。上下文压缩和重连必须保留剩余工作，同时不引入独立规划器或替换调度器。

<a id="decision"></a>
## 决策

在运行时内核中保留有序任务元数据，经现有 AgentState/JSONL 路径保存检查点。只有模型显式调用 `task_queue start` 才创建队列；顶层编号或项目符号格式绝不创建可执行任务。暴露小型队列工具，由模型选择语义任务边界。每个执行请求仅注入紧凑当前进度。任务局部失败允许建议性恢复及独立工作推进，现有执行预算保持全局。最终内容输出及 TurnFinished 必须满足队列终态和最终摘要要求，取消及全局错误仍可停止执行。

<a id="lifecycle-correction"></a>
## 生命周期修正

会话标识代表存储归属，不代表 Goal 标识。每个新顶层用户目标获得新 Goal ID，并取代／归档此前可恢复工作。恢复是匹配该 ID 的显式操作。任务完成必须显式转换队列状态，不能从最终文本推断。全局阻塞、致命错误和取消停止队列消费，并缓存一条终态响应；预算耗尽暂停工作。任务局部失败后继续独立任务。工作分支隔离队列元数据，同时记录父 Goal 标识。

<a id="consequences"></a>
## 影响

不新增规划器、调度器、数据库 schema、依赖或启动工作。最新队列状态独立于有界对话上下文恢复，跨提供商切换保留。语义分解和基于依赖的跳过仍依赖执行模型判断。恢复绝不盲目重放工具副作用。

<a id="child-execution-extension"></a>
## 子执行扩展

队列可接入组合根 `ChildHost`，提供独立子会话、工作区和记忆存储。控制器通过 `AgentSupervisor::run_child` 分发条目，复用现有内核循环，不增加执行器。工具显式绑定子作用域，不共享父会话状态。子执行终态回执先于控制器推进保存，以支持重连恢复。本地子任务失败后推进独立工作；控制器全局停止仍按原规则进入终态或暂停。不增加大型规划器或固定提示。

本地子执行持久状态现位于可丢弃工作区之外。Git 输入由 HEAD、二进制脏补丁及过滤后未跟踪文件组成；非 Git 输入使用过滤快照。终态回执使工作区可立即删除，不破坏控制器恢复。只有持有租约的运行中／中断工作区可恢复；有界准入、检查点配额和惰性到期 GC 限制磁盘占用，同时保留原始历史。GC 绝不只因心跳过旧就删除运行进程持有租约的工作区。

共用前端接线、完整任务输入及未执行计划替换见 [0015](0015-shared-child-composition.zh-CN.md)。
