# 0023. 具有作用域的递归子代理限制

[English](0023-scoped-subagent-depth.md) | **简体中文**

<a id="decision"></a>
## 决策

允许非负 `max_depth`，保留深度 1、并发 8 的默认值。深度 0 禁用两种委派工具。AX 负责验证、全局持久化和项目覆盖；Crew 经 `ax settings --scope global|project` 管理同一组值，提供显式保存和重置。

各委派子代理接收不可变绝对深度、继承限制、直接父级工作区 host 及委派工具白名单。工具重新绑定到子代理，不从父代理复制。达到深度上限或工具选择为空／被禁时，子代理不能委派。通用工作流子任务及任意 worker fork 仍没有委派 host。

轮次级共享池限制所有存活后代，等待中的祖先也计入，最多接纳 64 个总任务。根任务仍可排队，嵌套任务在资源耗尽时失败，不排到自身祖先后方。ID 在整棵树内唯一，后代生命周期事件传播时不携带子对话记录。取消向树下级联并关闭持久回执。

委派工具等待子代理期间不持有进程级副作用租约；子代理实际副作用工具获取这些租约，避免递归共享工作区死锁，同时保留副作用串行化。

<a id="consequences"></a>
## 影响

取代 ADR 0010 的默认禁用及禁止递归委派。限制在下一父轮次生效。模型决定是否委派，提高上限本身不会启动工作或扩大权限。
