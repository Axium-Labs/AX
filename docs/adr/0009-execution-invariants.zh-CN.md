# 0009. 绑定 Goal 的执行不变量

[English](0009-execution-invariants.md) | **简体中文**

状态：由 [0014](0014-advisory-execution-policy.zh-CN.md) 修订

下述前驱进度和恢复准入决策属于历史行为。ADR 0014 保留资源／安全约束及权威执行历史，但以建议性编排策略替代语义执行门槛。

<a id="context"></a>
## 背景

对话摘要保留陈述的目标，却未将实际工具调用绑定到步骤、目录或已观察进度。恢复鼓励发现工作区，却未强制边界。压缩历史可能使模型误报自身工具使用，尤其当 UI 展示子代理工具时。

<a id="decision"></a>
## 决策

在现有内核保留轻量可序列化 ExecutionState。当前执行模型为普通调用提供步骤绑定，运行时检查 Goal 标识、前驱进度及声明资源。实际完成事件更新状态，经 AgentState 保存检查点；恢复绕过有界对话选择。子执行完成事件通过持久游标吸收。

八次调用无进展窗口触发有界步骤恢复和上下文重选，不使用关键词路由或独立规划器。三次重试失败强制改变策略。搜索有显式工作区回退，以及固定遍历数、深度、文件大小和耗时上限。工具自有存储使用显式资源声明，而非工具名权限启发式。

<a id="consequences"></a>
## 影响

作用域和进度可独立于对话压缩强制执行。原始历史保持权威，短任务不增加模型往返。读取密集任务可在八次观测后收到保守停滞干预；结构化结果证据可验证输出。成功的声明变更是执行证据，不是任意结果满足用户要求的语义证明。不透明副作用扩展没有作用域资源声明就不能启动新恢复操作。状态投影使用现有 ContextBudget，事件预览有界。
