# 0034. 需审核的 Evolution 晋升与有界分析恢复

[English](0034-reviewed-evolution-and-analysis-recovery.md) | **简体中文**

状态：已接受；补充 ADR 0006 和 ADR 0017。

<a id="context"></a>
## 背景

创建证据超出运行时窗口后无法退役。单个格式错误的分析动作可能永久卡住待处理批次。候选立即晋升会在没有后续证据或用户审核时暴露新生成指令。账本失败可能留下未跟踪 Skill 目录。

<a id="decision"></a>
## 决策

退役依据归属／摘要及后续显式 RETIRE 删除，不要求原始证据。候选晋升需要后续 epoch 和新证据，再排队等待绑定内容摘要的 TUI 审核。接受后进入 trial，拒绝则归档；ACP/run 不能接受。Trial 到 active 的使用门槛保留。

逐个尝试左方括号，采用首个可解析 JSON 数组；审计无效动作及 max_actions 截断。无效响应尝试以待处理批次起始 processed 游标持久化，不受新增观测影响。三次无效响应后先审计跳过，再仅推进选中批次；超时及提供商／网络错误只影响退避。持久化指数冷却，最高 24 小时，成功分析重置。Config 保留 120 秒超时。持久化／审计错误不能推进失败工作，原始 JSONL 不可变。

每个 Experience 检查点仅记录一次使用量／游标。不序列化重复意图，也不向分析器暴露旧评分配置，保留旧读取支持。要求有实质内容的用户原文来源。包中排除归档正文。账本失败回滚新建包；MERGE 先检查来源归档，对普通移动／检查点失败作整体回滚。

<a id="consequences"></a>
## 影响

学习仍是内核外尽力处理。三次无效模型响应可能跳过一批学习，但保留持久审计及原始数据供检查。没有 TUI 审核时，候选可无限等待。文件、账本、Memory 和审计仍非崩溃原子事务。已有旧配置字段仍可读，但无语义决策权。
